01 / Machine learning · Team project

Credit Card Fraud Detection

A proof of concept for identifying suspicious transactions in an imbalanced dataset, where fraudulent examples are much rarer than legitimate ones.

My role
Team lead for the VUT Business Analysis project.
The work
Data preparation, class balancing and a comparison of classification models, with evaluation focused on fraud detection.
  • Python
  • scikit-learn
  • pandas
  • SMOTE

02 / API development · Computer vision

IdentityGuard

An identity-verification prototype that brings document text extraction, face comparison and liveness checks into a Python API.

The approach
FastAPI endpoints connect the image-processing modules; a Java client demonstrates how another application can use the API.
The learning
Connecting computer vision with a service interface and integrating across languages.
  • Python
  • FastAPI
  • OpenCV
  • Java
